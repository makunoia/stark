# Archive restoration history

The archive originally used PropTypes, missing stark-types declarations, older
Headless UI APIs, react-quill, react-input-mask, unpublished deep imports and old
Tailwind color names. Its components and examples were first made runnable in a
separate Restored catalog.

That temporary separation has been removed. The components are now consolidated
with the active library and documented together, prioritizing the original
appearance. See [Component consolidation](COMPONENTS.md) for the current APIs,
compatibility names, Storybook organization and verification workflow.

The original archive directories remain excluded historical references.
